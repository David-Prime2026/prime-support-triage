```
  ├─ else POST apx bricely-diagnose { text, state, newAttachments }

  │     │     HOW_TO regex hit → generic “walk that through…” (no Tonnage History steps)

```

## Efficacy and turns (live diagnose POSTs)

Page context is what Portals sends (`state.screen` = Seller Home / home). That is the production contract.

| Input | Live `internal_reason` | User sees |
|---|---|---|
| `what is my tonu` + `screen: Seller Home` | `default_escalate_no_reask` | specialist 24h, ticket |
| `what is my tonnage` (no state) | `default_escalate_no_reask` (`inferScreen` matches `tonnage`) | same |
| `what is my tonu` (blank state) | `ask_surface_once` | “Which screen…?” — also wrong for a how-to |
| `How can I see tonnage history` | `how_to_direct_answer` | “I can walk that through with the product as it exists today…” — no steps |
| `how do I reset my password` | `existing_capability_how_to` | “I've got this handled. Try that path again.” |
| `which buyers still owe me` | `ask_surface_once` | which-screen, not accounting |
| `change my welcome name to Dave` | `welcome_name_live_fix` | live-fix JSON — only works if embed honors `liveFix` |
| `the load board filters are broken` | `justified_clear_filters` | one safe step (this path is the only one that still looks like the design) |
| Repeat “still wrong” after that | escalate on **turn 2**, then `hold_escalate_no_reask` forever | no 5-turn offramp |

`HOW_TO` only matches `how do I` / `how to` / `where is` / `can I`. **`what is my tonnage` is not classified as a how-to.** Combined with page `screen` already set, policy skips “which screen?”, has no `problem` fact, and dumps to `default_escalate_no_reask`. That is Lori’s screenshot, byte-for-byte.

Intended ~5 turns then offramp (`DEFAULT_TURN_TARGET = 5`) never runs on that path.

## Recommendations (priority)

### P0 — CS on `apxbwdx` (this repo, Support seat deploy)

1. **Deploy `bricely-diagnose` from CS `main` `4e17f46`.** Prove: POST with `state.openTicketId` = missing UUID must **not** return `ticket_followup_accepted`. Expect lock clear / `terminal_ticket_new`. This VM cannot deploy.
2. **Do not escalate a how-to because the portal sent a page screen.** Seller Home + `what is my tonnage/tonu` should answer Tonnage History (nav is on that chrome) or ask one useful follow-up. Treat `what is` / `where is my` as how-to. Page context is a hint, not “facts complete.”
3. **Replace waffle copy with real steps** for: Tonnage History, load board export (already has one good sentence), password reset, idle stores. “Try that path again” is not an answer.
4. **Fix `process-ticket-ai` model id** (`claude-sonnet-4-20250514` 404). Until that 200s, widget tickets are a hole. Drain `WMG-2026-10-013` and `014` on the desk after.
5. **Disable or auth-fence `bricely-claude-assist`.** HVAC tonnage on a WMG seller ask is a landmine if anything routes to it.

### P0 — Main / Wmsosv2 (packet only; do not mix into this PR)

6. **Card = `ticket.ticket_number`.** Stop `id.slice(0,8).toUpperCase()`. Intake already returns the row (`select *`); the number is on the row.
7. **Delete the local `if (openTicketId) specialist wall`.** After a ticket, keep POSTing diagnose / append. CS cannot fix a branch the embed never calls.
8. **Intro:** one line for the page they are on. Not “I'll ask a few questions. What's going on?” after they already typed the ask.
